# Qian-Wei Yang｜Personal Portfolio

個人作品集網站，主要用於呈現個人的學習經歷、教育相關作品、數位教材設計、研究興趣與專業能力。

網站以「教育 × 數位 × 創意」為核心概念，希望透過簡潔、溫暖的視覺設計，呈現教育專業與數位創作之間的連結。

## 🌷 Website

**Personal Portfolio｜Qian-Wei Yang**

網站主要分為以下幾個部分：

- About Me｜關於我
- Selected Works｜作品集
- Experience｜學習與經歷
- Research｜研究
- Skills｜能力與工具
- Contact｜聯絡方式

網站預留未來作品的位置，可隨著學習與創作經驗增加持續更新。

## 🎨 Design Concept

網站整體採用溫暖的大地色系與粉色作為主要視覺配色。

### Color Palette

- Cream｜米白色
- Brown｜棕色
- Pink｜粉色
- Sage｜鼠尾草綠
- White｜白色

整體希望營造出：

> 溫柔、自然、簡潔、具有教育感與個人特色

的視覺氛圍。

首頁使用拱門造型的白色人物區塊，搭配粉色圓形作為主要視覺元素，象徵個人品牌與作品展示。

## 🚀 How to Use

### 1. Download / Clone Project

將整個專案資料夾下載至本機。

### 2. Open Website

直接使用瀏覽器開啟：

```text
index.html
```

即可查看網站。

### 3. Update Personal Information

可以直接在 `index.html` 中修改：

* 姓名
* 個人介紹
* 作品內容
* 學習經歷
* 研究方向
* 技能
* Email

---

## ✏️ How to Add a New Work

如果未來需要新增作品，可以複製現有的：

```html
<article class="work-card">
```

區塊，並修改：

* 作品編號
* 作品分類
* 作品名稱
* 作品介紹
* 使用工具

即可新增作品卡片。
