02 / HTML × CSS PRACTICE

第二週
網頁設計練習

本頁整理第二週課程的學習成果，依照課程要求練習 HTML、CSS、RWD（響應式網頁設計）與網頁無障礙檢核， 並記錄其中一項 CSS 修改與驗證的過程。

HTML 01–04 CSS 05–09 RWD Accessibility GitHub Pages
LEARNING TASKS

本週課程內容

01 / HTML

把小站變成我的

練習標題、段落、粗體、斜體、上下標等 HTML 文字標籤，並加入自己的學習目標。
02 / HTML

讓小站有聲音

練習圖片、alt 替代文字、audio、video 與 SVG，將多媒體內容加入網頁。
03 / HTML

整理我的學習計畫

使用 table、caption、tr、th、td、thead、tbody 製作學習計畫表格。
04 / HTML

設計一張活動報名表

使用 label、input、select、radio、checkbox、textarea 與 button 製作表單。
05 / CSS

同一份內容，換一種風格

練習文字顏色、字體大小、padding、margin、border-radius 與卡片樣式。
06 / CSS

我的網站適合哪種版型？

使用 CSS Grid 調整欄位比例與網站版型，思考內容適合的呈現方式。
07 / CSS

把內容排得整整齊齊

練習卡片排列、Flex、圖片尺寸與內容高度，使作品內容呈現一致。
08 / CSS

從電腦版變成手機版

使用 RWD 與 @media 調整網頁，使內容在不同螢幕尺寸下都能正常閱讀。
09 / CSS

先檢核，再修正無障礙問題

使用 WAVE 檢查網頁，找出問題後手動修改 HTML/CSS，再次確認改善結果。
MODIFICATION & VERIFICATION

CSS 修改與驗證紀錄

原本的問題

作品卡片中的圖片尺寸不一致，排列時容易造成卡片高度不同，整體版面不夠整齊。

我的修改

透過 CSS 統一卡片圖片高度，並使用 object-fit: cover 讓圖片維持一致的顯示比例。

修改後驗證

重新整理網頁並檢查作品卡片排列，確認圖片高度一致；再縮小螢幕確認版面仍能正常顯示。

FINAL CHECK

課程完成檢查

  • 完成 HTML 活動 01～04 的指定練習。
  • 完成 CSS 活動 05～09 的指定練習。
  • 確認修改後的 HTML 與 CSS 檔案能正常開啟。
  • 確認 GitHub Pages 上的公開頁面已更新。
  • 確認圖片、音訊、影片與 SVG 等素材路徑正確。
  • 確認網站在手機尺寸下仍能閱讀與操作。
  • 使用 WAVE 進行無障礙檢查並修正發現的問題。
  • 保留一項 CSS 案例的「原本問題 → 修改方式 → 驗證結果」紀錄。
